# Baquiano - Sistema de Gestión para Fiambrería
Sistema modular con interfaz gráfica para el control de inventario y facturación rápida en caja mediante lector de código de barras.

## Requisitos
- Python 3.10 o superior
- CustomTkinter

## Cómo ejecutar
1. Instalar dependencias: `pip install -r requirements.txt`
2. Iniciar la aplicación: `python main_gui.py`
